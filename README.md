# Mortgage site

Tailwind CSS v4 + vanilla JS.

```
npm install
npm run dev      # watch CSS  (src/css -> dist/css/style.css)
npm run build    # minified build
npm run serve    # static server
```

- `src/css/` tokens (theme + measured sizes), base, components, animations
- `src/js/modules/` reveal, stack, horizontal, wordmark; `main.js` boots them
- Images are Unsplash placeholders; swap the `src` attributes in `index.html`
